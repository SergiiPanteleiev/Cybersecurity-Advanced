### **Крок 5: Аналіз зображення, отримання прихованих даних**

Дослідимо зображення кота на наявність в ньому прихованої інформації. Цей спосіб збереження даних називається стеганографією.
Якщо зображення не показує нічого очевидного, в ньому можуть бути приховані дані. Перевіримо наявність прихованих повідомлень за допомогою інструментів стеганографії. Для цього використаємо **steghide** — популярний інструмент стеганографії, який дозволяє приховувати та витягувати дані у зображеннях та аудіофайлах. Встановимо **steghide** за допомогою команди:
```sh
sudo apt install steghide
```
**Результат**:
Інструмент для вилучення прихованих даних встановлено.

Скористаємося наступними параметрами команди **steghide**.
- Параметер **extract** вказує **steghide* спробувати отримати будь-які приховані дані.
- Прапорець **-sf** вказує на файл, який потенційно містить приховану інформацію. В нашому випадку стеганографічним файлом є зображення **trytofind.jpg**.

Також **steghide** може запропонувати нам ввести пароль. В цьому випадку спробуємо ввести ключ 3xtr4ctd4t4. Отже виконаємо команду:
```sh
steghide extract -sf trytofind.jpg
```
**Результат**:
Наш ключ **3xtr4ctd4t4** спрацював і **steghide** повідомив нам, що приховані дані за зображенням було вилучено у файл з назвою **data.txt**.

### **Крок 7: Підбір пароля користувача renu**

Спробуємо підібрати пароль по протоколу ssh за допомогою команди **hydra**.
Це вбудований у **Kali Linux** інструмент, який використовується в кібербезпеці та тестуванні для швидкого підбору паролів методом брутфорс (перебору) у реальному часі. Hydra підтримує понад 50 протоколів, включаючи ʼSSHʼ, ʼFTPʼ, ʼHTTPʼ, ʼHTTPSʼ, ʼSMBʼ.
Спробуємо підібрати пароль користувачу на ім'я **renu**. Скористаємося наступними параметрами команди **hydra**.
- **hydra** це команда для запуску hydra, інструменту для злому паролів методом повного перебору;
- прапорець **-l renu** вказує ім'я користувача для входу, яке буде використовуватися для атаки повним перебором; в нашому випадку це ім'я користувача **renu**;
- прапорець **-P /usr/share/wordlists/rockyou.txt** вказує шлях до файлу зі списком паролів, який hydra використовуватиме для атаки; ми використовуємо **rockyou.txt**, який є популярним списком слів, що часто використовується для злому паролів;
- параметр **-f** вказує hydra зупинитися після першого успішного входу;
- параметр **192.168.160.234** задає цільову IP-адресу для служби ʼSSHʼ;
- параметр **ssh** вказує на протокол, по якому відбуватиметься вхід.
```sh
hydra -l renu -P /usr/share/wordlists/rockyou.txt -f 192.168.160.234 ssh .
```
**Результат**:
Ми отримали пароль **987654321** користувача **renu**.
