### **Крок 2: Веб-розвідка та пошук прихованих директорій**

Відкриваємо в браузері **http://192.168.160.201**.

![alt text](./Images/image3.png)

Зходимо в директорію **site**

![alt text](./Images/image4.png)

Досліджуємо веб сторінку. На головному меню бачимо в рядку статусу браузера, що під пунктом **Buscar** цікаве гіперпосилання із змінною в **URI (URL)**. 
Спробуємо дослідити змінну **buscar** на вразливості. Надамо значення змінній **buscar** у вигляді будь-якої команди **ОС Linux**, наприклад: **pwd**, **ls** чи будь-що інше.

**Результат**:
- Після вводу команди **pwd** виводиться шлях поточної директорії. Це директорія веб сервера **/var/www/html/site**.
- Після вводу команди **ls** виводиться перелік доступних директорій: **assets busque.php css index.html js wordpress**.
- Після вводу команди **ip a**  виводяться дані про **IP і MAC адресу**.

![alt text](./Images/image5.png)

![alt text](./Images/image6.png)

![alt text](./Images/image7.png)

Спробуємо дослідити вміст директорії якою управляє веб сервер **/var/www/html**

**Результат**:
Бачимо перелік файлів і директорій, серед яких **.backup**.
```plaintext
total 16 drwxr-xr-x 3 root root 4096 Oct 31 2021 . drwxr-xr-x 3 root root 4096 Oct 31 2021 .. -rw-r--r-- 1 www-data www-data 336 Oct 31 2021 .backup drwxr-xr-x 6 www-data www-data 4096 Jun 10 2021 site
```
![alt text](./Images/image8.png)

Спробуємо подивитися його вміст

**Результат**:
Знайшли облікові дані користувача
**username = jangow01**
**password = abygurl69**

### **Крок 3: Дослідження вмісту директорій на FTP**

Використовуючи знайдені облікові дані користувача на попередньому кроці, спробуємо авторизуватися через **ftp**:
```sh
ftp jangow01@192.168.160.201
```
**Результат**:
Зайшли на маштну через **FTP**.

![alt text](./Images/image10.png)

Спробуємо дослідити вміст домашньої директорії користувача. Як видно є ще один флаг **user.txt**. Переносимо його на локальну машину для досліджень.
```sh
cd /home/jangow01
ls
get user.txt
```
![alt text](./Images/image11.png)

Передивляємося вміст **user.txt**:
```sh
cat user.txt
```
**Результат**:
Знайшли значення, яке може бути паролем: **d41d8cd98f00b204e9800998ecf8427e**.

![alt text](./Images/image12.png)

### **Крок 4: Дослідження потенційних шляхів для підвищення привілеїв**

Дивимося дані про ОС та ядро через вразливий вебпараметр **buscar=uname -a**

![alt text](./Images/image13.png)

в **Exploit Database** для ядра цільової машини є сценарій, який допоможе нам отримати права **root** `https://www.exploit-db.com/exploits/45010`.
Зберігаємо сценарій, копіюємо на цільову машину з використанням **FTP**.
```sh
cd Downloads
ls -lah
ftp jangow01@192.168.160.201
cd /home/jangow01
put 45010.c
```
**Результат**:
Завантажили файл з експлойтом на цільову машину через **ftp**

![alt text](./Images/image14.png)

Пробуємо скомпілювати експлойт та надати права виконання для створеного файлу через вразливий вебпараметр **buscar=gcc /home/jangow01/45010.c -o exploit && chmod +x /home/jangow01/exploit**
